# Template ODT da LD

Coloque aqui o template oficial da empresa quando for implementar a geração real:

```text
templates/modelo_ld_empresa.odt
```

## Como preparar

1. Abra uma LD real no LibreOffice Writer.
2. Salve uma cópia como `modelo_ld_empresa.odt`.
3. Remova dados reais da tabela.
4. Mantenha estilos, margens, rodapé, cabeçalho e propriedades.
5. Deixe marcadores claros:

```text
{{TITULO_SECAO}}
{{NUMERO_FOLHA}}
{{ARQUIVO}}
{{DESCRICAO}}
```

6. Salve em formato `.odt`.

## Não fazer

Não converter para DOCX.

Não recriar layout em HTML.

Não deixar dados reais antigos no template.
