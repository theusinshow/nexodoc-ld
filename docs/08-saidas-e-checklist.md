# Saídas e Checklist Final

## Saídas obrigatórias

Sempre gerar:

```text
[código]_[disciplina]_ld_[revisão].odt
[código]_[disciplina]_ld_[revisão].pdf
```

Se houver alertas/inconsistências não bloqueantes:

```text
[código]_[disciplina]_ld_[revisão]_inconsistencias.md
```

Sempre oferecer ZIP:

```text
[código]_[disciplina]_ld_[revisão].zip
```

## Downloads

Após a geração, oferecer:

```text
[Baixar ODT]
[Baixar PDF]
[Baixar relatório MD], se houver
[Baixar tudo em ZIP]
```

## Relatório MD de inconsistências

O relatório não deve alterar a LD oficial.

Ele registra:

```text
- folhas faltantes;
- disciplinas divergentes;
- totais divergentes;
- leituras com baixa confiança;
- alertas marcados como revisados;
- correções manuais relevantes, se útil.
```

## Checklist final

Após gerar os arquivos, mostrar checklist visual na tela.

O checklist não deve ser baixado nem entrar no ZIP.

Checklist sugerido:

```text
[ ] Abrir o arquivo .odt no LibreOffice Writer
[ ] Conferir se o rodapé está atualizado
[ ] Conferir se as propriedades do Writer foram preenchidas corretamente
[ ] Conferir se o nome do arquivo está correto
[ ] Conferir se o PDF abriu corretamente
[ ] Conferir se cada tomo começa em uma nova página
[ ] Conferir se nenhuma tabela de tomo quebrou entre páginas
[ ] Conferir se a coluna Nº DA FOLHA está correta
[ ] Conferir se a coluna ARQUIVOS está correta
[ ] Conferir se a coluna DESCRIÇÃO copiou exatamente o campo CONTEÚDO das pranchas
[ ] Conferir o relatório .md de inconsistências, se houver
```
